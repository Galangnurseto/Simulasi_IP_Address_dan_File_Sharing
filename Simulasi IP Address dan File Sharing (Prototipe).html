Simulasi IP Address dan File Sharing

Prototipe proposal UTS Teknologi Pembelajaran, kelas XI Jaringan Komputer. Ubah konfigurasi, jalankan ping, lalu coba akses folder.

Pengantar: network ID

Dua komputer dapat saling berkomunikasi langsung jika network ID-nya sama. Network ID didapat dari IP address dan subnet mask.

192.168.1.10 dengan 255.255.255.0 menghasilkan network ID 192.168.1.0

Bagian bergaris bawah (192.168.1) menunjukkan jaringan; angka terakhir (10) menunjukkan komputernya.

PC-A (pengirim)

PC-B (pemilik folder “Data”)

Langkah 1: uji koneksi

Langkah 2: akses folder dari PC-A

Skenario selesai

Setelah selesai, tulis kesimpulanmu di LKPD: bagian IP mana yang menentukan satu jaringan?

Kuis akhir dan ringkasan

Ringkasan: network ID = IP address AND subnet mask. Dua komputer satu jaringan jika network ID-nya sama. IP address tidak boleh sama. Folder dibuka dengan alamat \\IP-PC-B\NamaFolder setelah ping berhasil dan folder dibagikan.
